# The SDS Films — Sandy Design Studio

Brand films, corporate films, and aerial cinema from the team behind Sandy Design Studio.

## Highlights
- **Recent Film**: ASAL Aluminium Formwork Brand Film
- **The Reel**:
  - `01` · Corporate Film: The Corporate Film

- **Cinematic Hero**: Dynamic fanned cards with custom stills and smooth hover micro-animations.

## Local Development
To serve locally on port 8000:
```bash
python3 -m http.server 8000
```
Then navigate to `http://localhost:8000`.
